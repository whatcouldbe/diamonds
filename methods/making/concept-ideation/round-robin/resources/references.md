# Round Robin — References

**[Round Robin](https://www.luma-institute.com/round-robin/) — LUMA Institute**
The original method reference, including the standard paper template (available in Luma Workplace and in `resources/templates/`). The template is an 11x17 sheet folded into four sections:
1. **Challenge Statement** — written at the top, visible throughout
2. **Proposed Solution** — "Come up with an unconventional way to address the challenge"
3. **Why the Solution Will Fail** — "Review the proposed solution, and find a reason that it will fail. This is your chance to be the armchair critic!"
4. **Final Concept** — "Review the critique. Then, quickly generate an idea that resolves the issues raised."

Each section is separated by a fold line. Participants only see the section they're working on — the folds enforce both the sequence and the anonymity.
