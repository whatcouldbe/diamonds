## A note on provenance

This method was taught to the engine by a practitioner (What Could Be), so it carries lived facilitation knowledge, not reconstruction. The worked example and workshop materials are **anonymised real work**: the fictional concept *Fastulin* and persona *Claudia* are kept as-is (they name no real person or company), the real client is replaced throughout with the placeholder enterprise **Bankeo**, and real individuals are removed — except the initials *SM* / *DT* on the Fastulin critique, which are the authors' own.
