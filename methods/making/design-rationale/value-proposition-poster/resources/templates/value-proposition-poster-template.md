# Value Proposition Poster — Template

One page, three zones, read left to right. Reproduce as a single slide or large sheet.

```
┌─────────────────────────┬───────────────────────────────────────────┐
│  VALUE PROPOSITION      │  HOW IT WILL WORK                          │
│                         │                                            │
│  [Concept name]         │  [1] [2] [3]                               │
│                         │  [4] [5] [6]   ← six-panel storyboard      │
│  Our ____               │                                            │
│  help(s) ____           ├───────────────────────────────────────────┤
│  who want to ____       │  KEY QUESTIONS AND ASSUMPTIONS             │
│  by ____ ____           │  (desirability · feasibility · viability)  │
│  and ____ ____          │  [sticky] [sticky] [sticky] [sticky]       │
└─────────────────────────┴───────────────────────────────────────────┘
```

---

## Zone 1 — Value proposition statement

Fill in each blank. Be specific in every field.

> **Concept name:** ___________
>
> **Our** *[products and services]*
> **help(s)** *[customer segment]*
> **who want to** *[job to be done]*
> **by** *[verb] [customer pain]*
> **and** *[verb] [customer gain]*
> *(optional)* **unlike** *[competing value proposition]*

---

## Zone 2 — How it will work (six-panel storyboard)

Overwrite each question with a short, plain-language answer about one named customer. Add an icon to each panel; upgrade to simple images if time allows.

1. Who is the character in your story? What problem are they facing?
2. What is needed to help them solve their problem?
3. How do they get started?
4. What happens next?
5. What happens at the end?
6. What is the result? How does that make things better for your character?

---

## Zone 3 — Key questions and assumptions

Generate one question or assumption per sticky across three dimensions. Promote the critical ones (the deal-breakers) onto the poster.

- **Desirability** — What is an assumption we need to address? What is a question we still have about real customer pain/gain?
- **Feasibility** — What do we assume about our technical ability to build this? What's open about technology, capability, expertise?
- **Viability** — What do we assume about business value? What's open about cost, market, timeline, organisational impact?

---

## Layer 4 — Feedback prompts (added by reviewers)

When the poster is shared, reviewers add **initialled** stickies, placed where they apply on the poster:

- What clarifying questions do you have?
- What is strong about this work, and why? *(Rose)*
- What challenges might this work face, and why? *(Thorn)*
- How might we build on or strengthen this work? *(Bud)*

---

*Tooling note: the original deployments used PowerPoint slides with brand icon libraries and an AI assistant for the pressure-test passes. The template is tool-agnostic — paper, slides, or a digital whiteboard (Miro/Mural/FigJam) all work, as long as the three zones stay on one page.*
