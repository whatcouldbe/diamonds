# Hypothesis Statements — FAQ

`[Reconstructed / stub.]` These are plausible questions, not questions observed in real sessions. Per Pathway A step 3, a practitioner should add real ones and flag any of these as non-issues. Do not treat this as field-tested.

**How is this different from a problem statement or a How Might We?**
A How Might We opens a solution space. A hypothesis closes around a specific bet and attaches a disproof condition. HMW is divergent; this is convergent and falsifiable.

**How many hypotheses should a team write?**
The template supports five. Fewer, prioritised, beats comprehensive — a board of eight usually means no priorities. *(Reconstructed — no taught guidance.)*

**What if we can't write a quantitative impact?**
Then it is not yet a hypothesis. An unmeasurable bet is an opinion. If a number is genuinely impossible, the honest move is to find a qualitative signal you'd accept as disproof — but name it explicitly.

**Isn't writing the metric before the experiment backwards?**
No — the metric *is* the experiment's success threshold. Writing it first is what stops teams from moving the goalposts after the data arrives.
