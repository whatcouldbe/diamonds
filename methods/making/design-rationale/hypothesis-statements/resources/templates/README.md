# Hypothesis Statements — Templates

The method was reconstructed from a blank template and its worked example (a Mural-style board, up to five color-coded parallel hypothesis rows, dated header, team attribution, and a "See an example" affordance).

**Grounded structure:** one row per hypothesis; the fixed sentence frame with five fill-in variables (new feature, desired outcome, target persona, quantitative impact, high-level goal); dated and attributed as a living snapshot.

**Not yet here:** a redistributable template file. The original is a Mural board; its exact provenance is unconfirmed (see `../references.md`). If a practitioner supplies a shareable version, add it here and note the tool.
