# Rough & Ready Prototyping — Resources

This folder contains supplementary materials for the Rough & Ready Prototyping method, organized by type.

---

## What's Here

| File / Folder | What it contains |
|---|---|
| `tips.md` | Practitioner wisdom, facilitation gotchas, and things that trip people up |
| `reference-houde-hill-1997.md` | Distillation of Houde & Hill (1997) — the Role/Look & Feel/Implementation model, the pizza-box example, and the origin of the method name |
| `visuals/` | Concept drawings, the 1x/10x/100x pyramid sketch, the Time/Love Continuum sketch |
| `templates/` | Device frame templates, wireframe component library |
| `examples/` | Real prototype examples: physical, screen-based, service |

**Already covered elsewhere:**
- Overview and full method reference → `../method.md`
- Facilitation cheat sheet → `../mechanics.md`
- Teaching arc content → `../teaching.md`

## How to Use These Resources by Mode

| Mode | What to reach for first |
|---|---|
| **Teaching** | `visuals/` for the 1x/10x/100x pyramid and Time/Love Continuum → `examples/` for real prototype types → `../teaching.md` for the arc |
| **Facilitating** | `templates/` for device frames and wireframe library → `../mechanics.md` for the cheat sheet → `tips.md` for in-the-moment guidance |
| **Coaching** | `tips.md` for situational advice → `../method.md` for format selection and fidelity guidance |
| **Executing** | `templates/` for component library |
