# Abstraction Laddering — Resources

This folder contains supplementary materials for the Abstraction Laddering method, organized by type. Resources grow over time as practitioners use the method and contribute examples, templates, and organizational variations.

---

## What's Here

| File / Folder | What it contains |
|---|---|
| `tips.md` | Practitioner wisdom, facilitation gotchas, and things that trip people up |
| `faq.md` | Questions that come up repeatedly — grows over time |
| `ai-usage.md` | How to use Abstraction Laddering with AI tools, including the structured WHY/HOW prompt |
| `recipes.md` | How Abstraction Laddering connects to and sequences with other methods |
| `references.md` | External reading, videos, related frameworks, and further resources |
| `visuals/` | Sketch-planations, concept drawings, ladder diagrams |
| `templates/` | Tool-specific templates (Miro, printable) |
| `examples/` | Real sessions, organizational examples, filled-in ladders |

**Already covered elsewhere:**
- Overview and full method reference → `../method.md`
- Facilitation cheat sheet → `../mechanics.md`
- Teaching arc content → `../teaching.md`

## How to Use These Resources by Mode

| Mode | What to reach for first |
|---|---|
| **Teaching** | `visuals/` for ladder diagrams and concept drawings → `examples/` for real sessions → `references.md` for further reading → `../teaching.md` for the arc |
| **Facilitating** | `templates/` for the Miro board or printed template → `../mechanics.md` for the cheat sheet → `tips.md` for in-the-moment guidance |
| **Coaching** | `tips.md` for situational advice → `recipes.md` for method sequencing → `faq.md` for common questions |
| **Executing** | `ai-usage.md` for the structured WHY/HOW prompt and guidance on AI-assisted generation |

## Provenance

Files marked `source: canonical` contain core WCB methodology content. Files marked `source: custom` are organizational additions — examples, templates, or notes contributed by a specific team or context. Both are valid; the distinction helps future practitioners understand what is general and what is specific to one context.
