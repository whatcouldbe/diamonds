## Contributing an Example

When adding an example, include:
1. **Context** — what was being prioritized and why
2. **Items** — the 8–10 items that went into the matrix (anonymized if needed)
3. **Output** — where items landed and the suggested road map sequence
4. **What happened** — what the team did with the output, if known
5. **Source** — `canonical` for WCB examples, `custom` for organizational contributions
