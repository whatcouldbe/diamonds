# Critique — Resources

This folder contains supplementary materials for the Critique method, organized by type. Resources grow over time as practitioners use the method and contribute examples, templates, and organizational variations.

---

## What's Here

| File / Folder | What it contains |
|---|---|
| `tips.md` | Practitioner wisdom, facilitation gotchas, and things that trip people up |
| `faq.md` | Questions that come up repeatedly — grows over time |
| `ai-usage.md` | How to use Critique with AI tools, including simulation guidance |
| `recipes.md` | How Critique connects to and sequences with other methods |
| `references.md` | External reading, videos, related frameworks, and further resources |
| `visuals/` | Sketch-planations, protocol posters, concept drawings |
| `templates/` | Tool-specific templates (Miro, FigJam, printable) |
| `examples/` | Real critique sessions, organizational examples, filled-in artifacts |

**Already covered elsewhere:**
- Overview and full method reference → `../method.md`
- Facilitation cheat sheet → `../mechanics.md`
- Teaching arc content → `../teaching.md`

## How to Use These Resources by Mode

| Mode | What to reach for first |
|---|---|
| **Teaching** | `visuals/` for concept drawings and protocol poster → `examples/` for real sessions → `references.md` for further reading → `../teaching.md` for the arc |
| **Facilitating** | `templates/` for workspace setup → `../mechanics.md` for the cheat sheet → `tips.md` for in-the-moment guidance |
| **Coaching** | `tips.md` for situational advice → `recipes.md` for method sequencing → `faq.md` for common questions → `references.md` for further reading |
| **Executing** | `ai-usage.md` for simulation parameters and transparency guidance |

## Provenance

Files marked `source: canonical` contain core WCB methodology content. Files marked `source: custom` are organizational additions — examples, templates, or notes contributed by a specific team or context. Both are valid; the distinction helps future practitioners understand what is general and what is specific to one context.
