## How to Use These Resources by Mode

| Mode | What to reach for first |
|---|---|
| **Teaching** | `../teaching.md` (draft) → `../method.md` for the "show me" framing and the two forms. Where the arc is marked [needs practitioner], say so rather than inventing it. |
| **Facilitating** | `templates/retrospective-walkthrough-guide.md` for a completed-work inquiry → `../method.md` → Steps for the live form |
| **Coaching** | `tips.md` → `../method.md` → Facilitation notes, especially "confirm the inputs; don't import them" |
| **Executing** | Contextual inquiry is observation-based and simulates poorly — its value is in seeing the unexpected on real work. Help prepare the guide and synthesize notes; don't simulate the session as a substitute for running it. |
