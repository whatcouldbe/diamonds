# Interviewing — Resources

This folder contains supplementary materials for the Interviewing method, organized by type. Resources grow over time as practitioners use the method and contribute examples, templates, and organizational variations.

---

## What's Here

| File / Folder | What it contains |
|---|---|
| `tips.md` | Practitioner wisdom, do's and don'ts, and things that trip people up |
| `faq.md` | Questions that come up repeatedly — grows over time |
| `ai-usage.md` | How to use Interviewing with AI tools, including simulated interviews |
| `recipes.md` | How Interviewing connects to and sequences with other methods |
| `references.md` | External reading, videos, related frameworks, further resources |
| `visuals/` | Interview protocol drawing, sketch-planations |
| `templates/` | Protocol templates, note-taking templates, tool-specific setups |
| `examples/` | Real interview protocols, organizational examples |

## Provenance

Files marked `source: canonical` contain core WCB methodology content. Files marked `source: custom` are organizational additions — examples, templates, or notes contributed by a specific team or context. Both are valid; the distinction helps future practitioners understand what is general and what is specific to one context.
